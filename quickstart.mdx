In this quickstart you make one call to GetClean that fetches a quarterly report page, marks two passages in it and writes a summary. Then you read one section of the same record a second time. The second call costs nothing, because GetClean already holds the record and answers from the same copy.

## Before you start

You need an API key from `https://app.getclean.ai`. Every key carries an explicit list of scopes, and this quickstart uses three of them:

| Scope | Why this quickstart needs it |
| --- | --- |
| `contents:fetch` | The first call fetches a page. |
| `contents:model` | The first call asks for highlights and a summary, which a model may work on. |
| `contents:read` | The second call reads a section of the held record. |

Put the key in your shell. The SDKs read the same variable when you pass no key.

```bash
export GETCLEAN_API_KEY="your-api-key"
```

To call GetClean from code, install an SDK. The curl command below needs nothing else.

## Make the first call

Fetch the page, find two strings in it, and ask for a summary.

<CodeGroup>

```bash cURL
curl https://api.getclean.ai/v1/contents \
  -H "Authorization: Bearer $GETCLEAN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/q3", "highlights": ["Revenue rose 12%", "what drove the margin"], "summary": true}'
```

```python Python
from getclean import GetClean

client = GetClean()  # reads GETCLEAN_API_KEY

record = client.fetch_contents(
    url="https://example.com/q3",
    highlights=["Revenue rose 12%", "what drove the margin"],
    summary=True,
)

print(record.outcome.kind)  # delivered
print(record.summary)
print(record.id)            # cnt_3Fk9abaUhNX7t2eKkgfd3e
```

```typescript TypeScript
import { GetClean } from "getclean";

const client = new GetClean({ apiKey: process.env.GETCLEAN_API_KEY });

const record = await client.fetchContents({
  url: "https://example.com/q3",
  highlights: ["Revenue rose 12%", "what drove the margin"],
  summary: true,
});

console.log(record.outcome.kind); // delivered
console.log(record.summary);
console.log(record.id);           // cnt_3Fk9abaUhNX7t2eKkgfd3e
```

Read it from the top. Every record comes in this order, so the first member always says what happened.

| Member | In this answer | What it tells you |
| --- | --- | --- |
| `outcome` | `delivered`, reason `whole` | What happened. `whole` means all the engine kept of what the site served; it is not a promise that the page is the article. |
| `notices` | none | Facts to read before the result. A notice is never an error. |
| `markdown` | the page's text | The content, with `<mark id="h1">` and `<mark id="h2">` around the two passages found. |
| `highlights` | `h1` in `s1`, block `b3`; `h2` in `s2`, block `b9` | Where each string stands. The first stands in the page word for word, `exact`. The second is a question, so a model picked the block that bears on it, `judged`. |
| `summary` | one sentence | A model's summary, at most 1,500 characters, in the content's language. |
| `left_out` | navigation, 1,480 characters | What the main content left out, by kind and size. |
| `source` | title, publisher, dates | The page's own facts as its code declares them. GetClean does not check them against the page. |
| `cost` | 1 `contents`, 2 `model_steps` | The bill: the fetch, one model step for the judged string and one for the summary. |
| `expires_at` | 2026-11-06T08:40:12Z | When the hold ends: 48 hours after the last call on the record, never more than 30 days after it was made. |

<Note>
  The amounts in these answers are example figures, not GetClean's prices.
</Note>

## Read one section again, free

The second highlight stands in section `s2`. Read that section from the held record:

<CodeGroup>

```bash cURL
curl https://api.getclean.ai/v1/contents/cnt_3Fk9abaUhNX7t2eKkgfd3e/sections/s2 \
  -H "Authorization: Bearer $GETCLEAN_API_KEY"
```

```python Python
section = client.get_section(record.id, "s2")

print(section.section.title)  # Margin
print(section.truncated)      # False
```

```typescript TypeScript
const section = await client.getSection(record.id, "s2");

console.log(section.section.title); // Margin
console.log(section.truncated);     // false
```

The section's 1,810 characters fit under the default bound of 20,000, so the whole section came and `truncated` is false. The answer carries no `cost`: this call fetched nothing and billed nothing. It also moved the hold, so the record now lives until 48 hours after this call.
